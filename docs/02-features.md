# 02. 화면·기능 명세

요금, CS, 청소 기능은 이 문서에서 화면 단위로만 정리합니다. 계산 규칙과 정책은 [05](05-pricing-engine.md), [06](06-cs-messaging.md), [07](07-cleaning-ops.md)에 있습니다.

## 1. 정보 구조 (IA)

```
/login                      로그인·회원가입 (카카오 / 이메일)
/onboarding                 에어비앤비 연결 → 숙소 선택·별칭 → 기본 설정
/dashboard                  대시보드
/calendar                   예약·수익 (캘린더 / 예약 목록 / 월 수익)
/pricing                    요금 자동화 (개요 / 기간별 규칙 / 공실 시장가 / 당일 인하 / 변경 이력)
/inbox                      메시지 (인박스 / 예약 메시지 / 지식베이스 / 응답 설정)
/cleaning                   청소 (일정 / 직원 / 안내 발송 / 발송 내역)
/settings                   설정 (연동 / 숙소 / 알림 / 팀 / 구독)
/s/[token]                  직원용 일정 페이지 (로그인 없음, 후속)
```

### 공통 레이아웃

- **사이드바**: 위 메뉴. 메시지 메뉴에는 '답변 필요' 배지를 표시합니다.
- **헤더**: 페이지 제목과 부제(기존 도구와 동일), 숙소 선택기(전체 / 개별 숙소), 동기화 상태 배지, `지금 동기화` 버튼
  - 기존 배지 "25건 동기화됨"을 **"3분 전 동기화 · 예약 25건"** 으로 바꿔 신선도를 보여줍니다. 동기화 중에는 스피너, 실패 시 빨간 배지와 원인 링크를 표시합니다.
- **자동화 상태 표시**: 킬 스위치가 켜져 있으면 모든 페이지 상단에 "자동화 일시정지 중" 배너를 띄웁니다.
- **모바일**: 사이드바는 하단 탭으로 바뀌고, 캘린더는 주 단위 또는 리스트 뷰로 바뀝니다. 호스트가 이동 중에 쓰는 일이 많으므로 승인·발송·요금 수정은 모바일에서 한 손으로 가능해야 합니다.

### 공통 UX 원칙

1. **외부 영향 동작은 3단계**: 경고 문구("실제 에어비앤비 요금이 바뀝니다") → 미리보기(변경 전/후) → 확인. 실행 후 이력에 남깁니다.
2. **출처 표시**: 자동화가 만든 값(요금, 메시지)에는 어느 규칙이 언제 만들었는지 툴팁이나 라벨로 표시합니다.
3. **실시간 진행 표시**: 동기화·일괄 적용·발송은 활동 로그로 실시간 스트리밍합니다.
4. **실패는 원인과 다음 행동을 함께**: 예) "에어비앤비 세션 만료 — [다시 로그인]".

## 2. 온보딩·연동 (F1)

### 흐름

1. 회원가입: 카카오 로그인(기본) 또는 이메일. 베타 기간에는 초대코드를 받습니다(기존 '고유코드 인증' 대체).
2. **에어비앤비 연결**: 원격 로그인 창에서 호스트가 직접 로그인하고 2단계 인증을 거칩니다([04 §6](04-airbnb-integration.md#6-로그인과-세션-수명주기)).
3. **숙소 선택**: 계정의 리스팅 목록에서 관리할 리스팅을 고르면, 리스팅마다 숙소가 하나씩 만들어집니다. 각 숙소에 별칭을 지정합니다(예: `DMC역`). M6부터는 다른 채널 리스팅을 연결할 때 기존 숙소에 매핑하는 단계가 추가됩니다([10 §2](10-multi-channel.md#2-숙소와-채널-숙소)).
4. **초기 동기화**: 진행률과 로그를 실시간으로 표시합니다. 범위는 과거 12개월 ~ 향후 12개월 예약, 향후 365일 캘린더, 과거 12개월 정산입니다.
5. **기본 설정 확인**: 숙소별 체크인/아웃 시각(동기화된 값), 기본 청소비, 요금 최저/최고 한계

### 사전 점검 (연결 직후 + 매일)

| 점검 | 조건 | 표시 |
|------|------|------|
| 스마트 요금 | 에어비앤비 스마트 요금 ON | "스마트 요금이 켜져 있어 요금 자동화를 쓸 수 없습니다" + 요금 자동화 비활성 |
| 당일 예약 마감 | 당일 예약 마감 시각이 당일 인하 종료 시각보다 이름 | "18:00 이후 인하는 효과가 없습니다. 종료 시각을 18:00으로 바꿀까요?" |
| 에어비앤비 예약 메시지 중복 | 에어비앤비 자체 예약 메시지가 켜져 있음(확인 가능할 때) | "같은 안내가 두 번 갈 수 있습니다" |

## 3. 대시보드 (F2)

### KPI 카드

| 카드 | 값 | 정의 | 보조 문구 |
|------|----|------|-----------|
| 이번 달 예약 | 건수 | 기준월에 속하는 확정 예약 수 (취소 제외) | `정산일 기준 5건` |
| 이번 달 매출 | ₩ | 기준월 정산 내역 합계(호스트 실수령액, 조정금 포함) | `정산일 기준 · 실제 정산액` |
| 이번 달 순수익 | ₩ | 매출 − 지출 | `순수익률 84.9% · 수입−지출` |
| 다음 청소 | 날짜 | 오늘 이후 가장 가까운 청소일과 그날 건수 | `1건 청소 필요` |
| 가동률 (신규) | % | 판매된 박 / 판매 가능 박(차단일 제외) | 전월 대비 증감 |
| ADR (신규) | ₩ | 숙박 매출 / 판매된 박 | 전월 대비 증감 |
| 답변 대기 (신규) | 건 | 미응답 스레드 + 승인 대기 초안 | 클릭 시 인박스 |
| 오늘의 자동화 (신규) | 요약 | 당일 인하 진행 상황(시작가→현재가/최저가), 오늘 적용된 요금 변경 수, 발송된 메시지 수 | 클릭 시 상세 |

**기준 토글 (신규)**: `정산일 기준`(기본값, 기존 도구와 동일, 현금 흐름) / `숙박일 기준`(박 단위 안분, 운영 성과).
숙박일 기준 매출은 예약 정산액을 박 수로 균등 안분합니다. 월을 걸친 예약은 해당 월에 속한 박만큼만 잡습니다.

### 최근 활동

기존의 터미널형 로그 UI를 유지합니다(`12:41:10 ✅ 로그인 확인 — ...`).

- 대상: 동기화 진행/완료, 요금 변경, 메시지 발송, 청소 안내 발송, 오류
- 레벨 아이콘(정보/성공/경고/오류), 항목 클릭 시 관련 화면으로 이동
- Supabase Realtime으로 실시간 표시합니다. 30일이 지나면 삭제합니다.

### 연동 상태

| 항목 | 상태 값 |
|------|---------|
| 계정 | 로그인 사용자, 플랜 |
| 에어비앤비 연결 | 정상 / 재로그인 필요 / 보안 확인 필요 / 오류 (+ 마지막 확인 시각) |
| 알림 채널 | 알림톡 발송 가능 / 미설정 |
| 자동화 | 실행 중 / 일시정지 |

## 4. 예약·수익 (F3)

### 4.1 캘린더 (숙소별 월 보기)

기존 화면 구성을 유지합니다.

- **예약 막대**: 체크인일부터 체크아웃일까지 이어지며 라벨은 `게스트명 ·인원`입니다. 확정은 진한색, 대기는 연한색입니다. 막대를 클릭하면 예약 상세 드로어가 열립니다. 숙소가 여러 채널에 연결돼 있으면 막대 앞에 채널 배지를 붙입니다(M6).
- **일별 요금**: `₩12.6만` 형식
  - 공실: 강조색 + `✎` 아이콘이며 클릭하면 수정할 수 있습니다.
  - 예약된 날짜: 회색(판매가)
  - 자동화가 바꾼 날짜: 툴팁으로 출처를 표시합니다(예: "기간별 규칙 '주말 할증' · 10/01 00:10 적용").
  - 수동 고정 날짜: 자물쇠 아이콘
- **청소일**: 체크아웃일 우측 상단에 주황 점을 찍습니다.
- **오늘**: 셀 배경을 강조합니다.
- 범례: `예약(게스트)` `● 퇴실 = 청소일` `🔒 수동 고정` `막대·날짜 클릭 → 상세`

### 4.2 날짜 상세 패널 (날짜 클릭)

- 현재 요금, 희망 요금, 계산 근거(적용 레이어와 규칙명)
- 요금 수정: `이 날짜 고정`(기본, 자동화 제외) / `한 번만 적용`(이후 자동화가 덮어쓸 수 있음)
- 이 날짜 청소비 수정(기본 청소비 덮어쓰기)
- 메모

### 4.3 상단 설정 바

- **청소 1회 기본비용** (숙소별, 예: 27,000원): "퇴실(청소)일마다 이 금액이 지출 청소비로 자동 합산돼요. 날짜별로 다르면 그 날짜를 클릭해 수정."
- **자동 요금조정** 버튼: 당일 인하 설정 모달을 엽니다(기존 위치 유지, `/pricing`에서도 접근 가능).

### 4.4 예약 상세 드로어

| 영역 | 내용 |
|------|------|
| 게스트 | 이름, 인원(성인/어린이/유아), 언어 |
| 일정 | 체크인/아웃 일시, 박 수, 상태, 예약 코드 |
| 금액 | 게스트 결제액(가능 시), 호스트 수수료, **정산액**, 정산일, 정산 상태 |
| 메시지 | 스레드 바로가기, 예약 메시지 발송 예정/완료 목록 |
| 청소 | 연결된 청소 작업(체크아웃일, 담당자, 비용) |
| 링크 | 에어비앤비에서 열기 |

### 4.5 예약 목록 탭

테이블 컬럼은 게스트, 숙소, 체크인, 체크아웃, 박, 인원, 정산액, 정산일, 상태입니다. 필터는 기간, 숙소, 상태이고 CSV로 내보낼 수 있습니다.

### 4.6 월 수익 탭

- 요약: 매출 / 지출(카테고리별) / 순수익 / 순수익률
- **지출 관리**
  - 청소비: 체크아웃마다 자동 생성됩니다(기본 청소비, 날짜별 수정 반영). 예약이 취소되면 자동 삭제됩니다.
  - 수동 지출: 카테고리(소모품, 관리비, 공과금, 월세, 수리, 기타), 금액, 날짜, 숙소, 메모
  - 반복 지출: 월세처럼 매월 같은 날 자동 생성
- 월별 추이 차트(최근 12개월 매출/순수익)

## 5. 요금 자동화 (F4) — 상세: [05-pricing-engine.md](05-pricing-engine.md)

| 탭 | 내용 |
|----|------|
| 개요 | 숙소별 자동화 상태(켜짐/꺼짐/차단 사유), 다음 실행 예정, 요금 한계(최저/최고), 오늘 변경 요약, 숙소 단위 일시정지 |
| 기간별 규칙 (신규) | 규칙 목록(우선순위 순)과 편집 폼. 조건은 기간·요일·공휴일·남은 일수, 동작은 고정가·%·금액 조정, 대상 숙소, 우선순위. 겹치는 규칙은 경고합니다. 프리셋: 주말, 공휴일 전날, 성수기 |
| 공실 시장가 | 기존 '다음달 공실 자동 가격설정'(자동 설정 토글, 할인액, 매일 실행 시각)에 대상 범위, 최저/최고 한계, 반올림 단위를 추가합니다. |
| 당일 인하 | 기존 '자동 요금조정' 모달 필드(토글, 시작·종료 시각, 조정 주기, 1회 인하액, 최저 한계)에 실행 요일과 **오늘 진행 상태**(시작가 → 현재가, 다음 인하 시각, 종료 사유)를 추가합니다. |
| 변경 이력 | 날짜, 숙소, 이전가 → 새 가격, 출처(규칙명/수동/되돌리기), 결과, 시각. 개별·일괄 되돌리기를 지원합니다. |

공통:

- 규칙을 저장하거나 `지금 한 번 적용해보기`를 누르면 **미리보기 표**(날짜별 현재가 → 희망가, 근거, 건너뛴 사유)를 먼저 보여주고 확인을 받은 뒤 적용합니다.
- 기존 도구는 버튼을 누르면 바로 적용했습니다. 이번에 미리보기 단계를 추가합니다.
